# curlyk

Консольный HTTP-клиент в стиле продуктов JetBrains: редактируете `.http`-запросы
в TUI-редакторе с подсветкой синтаксиса, выполняете их, импортируете из cURL,
сохраняете ответы.

> **Внимание.** Весь код этого проекта полностью сгенерирован LLM (языковой
> моделью) и не подвергался ревью человеком-разработчиком. Используйте на свой
> риск: перед использованием в работе проверьте код, и особенно места работы
> с сетевыми запросами и пользовательским вводом.

## Сборка

```sh
go build -o bin/curlyk.exe ./cmd/curlyk
```

## Запуск

```sh
./bin/curlyk.exe [путь/к/файлу.http]
```

Без аргумента открывается встроенный пример.

## Язык интерфейса (i18n)

Интерфейс переведён на два языка: русский (по умолчанию) и английский. Язык
выбирается, в порядке приоритета:

1. переменная окружения `CURLYK_LANG` (например `CURLYK_LANG=en`);
2. настройка `lang` в `appsettings.yml` (например `lang: en`);
3. по умолчанию — `ru`.

Пустое значение или неизвестный код всегда приводятся к `ru`.

Язык можно переключить «на лету» прямо из приложения клавишей **`Ctrl+L`** —
интерфейс перерисуется сразу, а выбранный язык записывается в `lang:` в
`appsettings.yml` и применится при следующем запуске.

## Горячие клавиши

| Клавиша        | Действие                                  |
|----------------|-------------------------------------------|
| `Ctrl+Enter`   | Выполнить запрос под курсором             |
| `Ctrl+V`       | Вставить из буфера (cURL конвертируется в .http автоматически) |
| `Ctrl+Z`       | Отменить последнее изменение |
| `Ctrl+Shift+Z` | Повторить отменённое изменение (redo) |
| `Ctrl+Y`       | Удалить текущую строку |
| `Ctrl+K`       | Copy as cURL: скопировать запрос как curl-команду |
| `Ctrl+G`       | Навигация по запросам: попап со списком (фильтр по мере ввода) |
| `F1`           | Показать/скрыть справку по горячим клавишам в правой панели |
| `Ctrl+L`       | Переключить язык интерфейса (ru ⇄ en) |
| `Tab`          | Переключение панелей (редактор / ответ)   |
| `Alt+←/→`      | Горизонтальный скролл (наклон колеса тоже) |
| `Ctrl+D`       | Дамп состояния UI в `debug.txt`           |
| `Esc Esc` / `F10` | Выход                                  |

### Мышь

Клиент поддерживает мышь (включается автоматически):

- **Левый клик** в левой панели — перемещает курсор в редакторе на позицию клика
  (координаты учитывают ширину широких/кириллических символов).
- **Левый клик по иконке `▶`** слева от номера строки запроса — запускает запрос.
- **Левый клик** в правой панели — переключает фокус на панель ответа.
- **Зажатие и перетаскивание** левой кнопкой в редакторе — выделение текста.
- **Колесо мыши** — прокрутка активной панели (редактор или ответ).

### Иконка запуска

Слева от номера строки каждого блока запроса (строка вида `METHOD URL ...`)
рисуется иконка `▶`. Запустить запрос можно:

- кликом мыши по иконке `▶`;
- нажатием `Ctrl+Enter` или `Ctrl+R` (запуск сразу);
- нажатием `Enter` на строке запроса — открывает попап с действиями
  (▸ Выполнить, ⧉ Копировать как cURL, {} Форматировать JSON,
  ◇ Тело как ключ=значение), выбор стрелками и подтверждение `Enter`.

Пункт **«Тело как ключ=значение»** открывает редактор тела в формате
`application/x-www-form-urlencoded`: текущие пары `key=value` тела (если тело
уже было) разбиваются на строки, каждую можно править построчно. `Tab` —
переключение между ячейкой ключа и значения, `↓`/`Enter` — следующая строка
(создаёт новую пустую на дне), `Esc` — закрыть без изменений. По завершении
редактора тело пересобирается в закодированную строку `key=value&...`. Если у
запроса тела ещё не было, оно добавляется. Так удобно заполнять OAuth2-запросы
вида `grant_type=application&scope=...&token=...`.

### Навигация по запросам (`Ctrl+G`)

`Ctrl+G` открывает попап со списком всех запросов файла. Ввод с клавиатуры
фильтрует список по мере набора (по `@name` или по `METHOD URL` для безымянных
запросов), стрелки перемещают курсор, `Enter` прыгает на строку выбранного
запроса, `Esc` закрывает попап.

Именованным запросам (`@name ...`) присваивается имя. Аннотация `@name` может
стоять как над строкой запроса (`@name find` перед `GET ...`), так и сразу после
неё.

### Справка по горячим клавишам (`F1`)

При запуске, пока в правой панели нет ответа, там показывается краткая справка
по горячим клавишам. `F1` выводит её в любой момент поверх ответа (повторное
нажатие скрывает); следующий выполненный запрос автоматически возвращает панель
ответа.

## Выделение, копирование, вставка

Редактор поддерживает выделение и работу с буфером обмена (Windows/macOS/Linux):

- **`Ctrl+C`** — скопировать выделенное в буфер обмена (всегда копирует, никогда не выходит).
- **`Ctrl+X`** — вырезать выделенное.
- **`Ctrl+V`** — вставить из буфера обмена (в т.ч. многострочный текст).
- **`Ctrl+D`** — дамп состояния UI в файл `debug.txt` (текст редактора, позиции
  курсора, скролл, содержимое панелей, константы геометрии). Полезно для
  диагностики рендера и координат мыши.
- **`Esc` `Esc`** (дважды быстро) или **`F10`** — выход из приложения.
- **`Ctrl` + стрелки / Home / End** — перемещение курсора по словам.

### Способы выделения

- **Драг мышью** — зажать и перетащить в редакторе.
- **Двойной клик** — выделить слово под курсором (в т.ч. URL, кириллицу).
- **`Shift` + стрелки / Home / End** — расширение выделения с клавиатуры.
- **`Esc`** — снять выделение.

Выделенный диапазон подсвечивается тёмно-синим фоном.

Выделение и копирование работают **в обеих панелях** — и в редакторе, и в панели
ответа (драг мышью, `Shift`+стрелки, `Ctrl+C` для копирования).

### Запуск с клавиатуры

Курсор можно поставить на иконку `▶` (нажать `Home` на колонке 0, или `←` в начале
строки), затем `Enter` — выполнит запрос под курсором.

## Синтаксис `.http`

```
### Описание запроса (опционально)
GET https://api.example.com/items/1
Accept: application/json

### Создание записи
POST https://api.example.com/items
Content-Type: application/json

{"title": "тест"}
```

`###` разделяет запросы. Текст после строки заголовков до пустой строки — тело.

Подсветка выделяет: методы, URL, HTTP-версию, заголовки, тело, комментарии и
переменные `{{...}}`.

## Переменные

Перед выполнением места `{{name}}` в URL, заголовках и теле подставляются
значениями. Источники значений — файловые переменные и встроенные функции.

Файловые переменные объявляются строками `@var имя = значение` в любом месте
файла и доступны всем запросам:

```
@var host = http://api.example.com
@var apiKey = secret

GET {{host}}/users
Authorization: Bearer {{apiKey}}
```

Встроенные функции:

| Плейсхолдер | Результат |
|-------------|-----------|
| `{{$random.uuid}}` | Случайный UUID v4 |
| `{{$guid}}` | Алиас `$random.uuid` |
| `{{$random.int}}` | Случайное целое |
| `{{$timestamp}}` | Unix-время в секундах |
| `{{$isoTimestamp}}` | Текущее время в ISO 8601 |

Если переменная не определена, запуск прерывается и в статусной строке
показывается сообщение «Не определена переменная: имя» вместо того, чтобы
слать на провод сырой `{{...}}`. Значения, содержащие `{{...}}`, не
подставляются повторно.

## Опции запроса (processing options)

Поведение конкретного запроса при выполнении можно переопределить строками
вида `@option [значение]`, которые ставятся **сразу после строки запроса** и до
первого заголовка/тела:

```
GET https://api.example.com/slow
@timeout 5s
@no-redirect
@insecure
Accept: application/json
```

Поддерживаются:

| Опция | Значение | Эффект |
|-------|----------|--------|
| `@timeout` | `5`, `5s`, `500ms`, `2m` | Таймаут запроса (голое число — секунды). По умолчанию 30 с. |
| `@follow-redirects` | `on`/`off`, `true`/`false`, `yes`/`no` | Следовать 3xx-редиректам. |
| `@no-redirect` | — | Не следовать редиректам (по умолчанию). |
| `@insecure` | — | Отключить проверку TLS-сертификата. |

Опция из файла важнее дефолта; значения по умолчанию не меняются. Некорректное
значение `@timeout` (например `@timeout abc`) приводит запуск к ошибке с
сообщением в статусной строке.

## Импорт cURL

Скопируйте команду cURL в буфер и вставьте её в редактор через `Ctrl+V` (или
`Ctrl+Shift+V` в терминале):

```
curl -X POST https://api.example.com/x -H 'Content-Type: application/json' -d '{"a":1}'
```

При вставке команда автоматически конвертируется в блок `.http` в редакторе.

## Архитектура

- `internal/httpfile` — парсер `.http` + лексер (используется и для подсветки).
- `internal/curl` — импорт cURL: split командной строки + разбор флагов.
- `internal/runner` — выполнение через `net/http`.
- `internal/tui` — интерфейс (bubbletea): редактор, подсветка, панели.
- `internal/i18n` — каталог переводов интерфейса (`ru`/`en`) и функция `T()`.
