# Фича: подстановка переменных `{{var}}`

## Цель

Сейчас переменные `{{...}}` только подсвечиваются (`internal/httpfile/lexer.go`,
`TokVariable`, `VarSpan`), но перед выполнением не подставляются: `runner.Run` в
`internal/tui/app.go:464` получает запрос с сырым `{{...}}`. Нужно сделать реальную
подстановку значений перед отправкой.

## Предпосылки (текущее состояние)

- Лексер уже находит `{{...}}`-спаны относительно значения токена (`findVars`,
  `VarSpan`).
- Парсер `httpfile` поддерживает `@name` (`model.go`), но не секцию переменных.
- `runner.Options` (`runner.go:38`) не принимает подстановку; подстановка должна
  происходить на уровне tui перед `runner.Run`.
- `Request` (`httpfile/model.go`) имеет неизменяемые поля; подстановку лучше делать
  до сборки `http.Request` (отдельный шаг нормализации запроса).

## Дизайн источников переменных

- Локальная секция в самом `.http`:
  ```
  @var host = http://api.example.com
  get {{host}}/users
  ```
- Встроенные функции: `{{$random.uuid}}`, `{{$random.int}}`, `{{$timestamp}}`,
  `{{$isoTimestamp}}`, `{{$guid}}`.
- Внешний файл переменных (`.http-env.json` / `.env`) через настройку в `appsettings.yml`.
- (Опция, см. feature-response-history) динамическая подстановка из тела предыдущего
  ответа.
