# Фича: Code completion для hosts, методов, заголовков и переменных

## Цель

При редактировании `.http`-файла показывать автодополнение прямо в редакторе: HTTP-методы,
схему/хост (`http://`/`https://` и хосты из файла/профилей), имена заголовков и
переменные (`@var`/`{{...}}` из файла и активного профиля, плюс встроенные `$функции`).
Аналог в других инструментах: JetBrains HTTP Client, REST Client для VS Code и Postman
умеют всплывающие подсказки с табуляцией по кандидатам (completion popup).

    верхней части редактора (`navLines`/`navReserve`/`navHeight`, рендер в `render_editor.go:140`).
  - `keys.go:86` — `handleKey`; занятые хоткеи: Ctrl+C/X/V/Z/Y/D/K/L/G/S/N/A/+стрелки,

    читает `activeProfileVars()` (`profiles.go:140`).

## Дизайн

- **Чистый источник кандидатов — новый пакет `internal/completion`** (без UI, юнит-тестируемый).
  `Suggest(line string, col int, ctx Context) []Suggestion`. `Context` несёт: доступные методы,
  хосты, имена заголовков и переменные (все собраны вызывающим tui-модулем из `ParseFile`
  текущего буфера + активного профиля). `Suggestion` = `{ Label, Snippet string, Start, End int }`.

  **Детерминированная классификация контекста по позиции курсора.** Движок по строке и колонке
  курсора (а не только по наличию `{{`) распознаёт, *в каком месте* пользователь печатает, и
  собирает релевантные кандидаты. Возможно несколько совпадающих контекстов — движок объединяет
  их кандидаты, отсекая дубликаты по `Label`. Позиции/типы:

  - **Метод**: колонка в начале строки, до пробела, и текст до курсора без знака `:` собирается
    в какое-либо известное имя метода или его префикс (по первой букве) → кандидаты из набора
    HTTP-методов; поддерживаем ввод в нижнем регистре (`get` → `GET`).
  - **URL: схема/префикс**: после пробела после метода (или строка, начинающаяся с `http`/`www`)
    → кандидаты `http://`, `https://`, `www.` + хосты из контекста.
  - **URL: хост/домен и его части**: курсор внутри части после `://` до первого `/`, `?` или `:`
    → кандидаты хостов (из файла/профилей/истории); а по частям хоста (`http`, `.com`, `www`)
    — подсказки окончаний: после первой буквы домена предлагать `имя.com`, при набранном `имя.`
    — суффиксы `.com`/`.ru`/`.org` (`www` → `www.`) и т.п.
  - **Заголовок**: строка `Name: value` с курсором в поле `Name` (до первого `:`) → кандидаты
    имён заголовков.
  - **Значение заголовка / тело**: присутствует `{`/`{{` или курсор внутри `{{...}}` → кандидаты
    переменных (без префикса `{{`); незакрытый `{{` считаем префиксом для фильтрации.
    Также после `Content-Type:` в значении — кандидаты media-типов (`application/json`, …).

  Фильтрация по «что набрано после точки входа контекста»:
  - по **первой букве** набранного префикса (для методов/заголовков — без учёта регистра);
  - для URL-частей — по префиксу включая промежуточные символы (`web` → `webapi.example.com`).
  Возвращаемый `Suggestion.Start..End` — диапазон замены (колонки позиции входа контекста..курсор),
  который tui использует при accept.
- **Попап завершения в tui** — новый `internal/tui/completion.go` по образцу `navigation.go`:
  поле `complete *completionMenu` в `model` (`app.go`), рендер через существующий механизм
  «плавающий блок у верха редактора» в `render_editor.go`, резервирование строк
  (`completeReserve`/`completeHeight`) аналогично `navReserve`. Когда попап открыт — он
  потребляет клавиши (в `handleKey` после проверки `dialog`/`search`, до обычной печати).
- **Триггер**:
  - явный хоткей `Ctrl+Space` — открыть попап в текущем контексте (стандартное сочетание
    автодополнения в редакторах; `keys.go` не использует пробел как модификатор, так что
    `ctrl+space` не конфликтует с существующими хоткеями);
  - автоматический — при наборе открывающей скобки `{` (после `{` смотрим, не `{{` ли это)
    внутри URL/заголовка/тела; и при вводе символа сразу после уже открытого `{{`.
  Фильтр в попапе — инкрементальный по типу «что набрано после `{{` / после метода /
  после `:` в имени заголовка».
- **Accept**: Enter/Tab заменяет диапазон на `Snippet` (для переменных — `name}}`, закрывая
  `{{`, если пользователь ещё не допечатал `}}`), попап закрывается. Esc закрывает без изменений.
  Правка входит в текущий undo-батч (`startEditBatch`), чтоб accept был одним undo-шагом.
- **Подсветка/справка**: строка в `help.go` `helpKeyCombos` (запись `Ctrl+Space — автодополнение`).
- **i18n**: все UI-строки попапа (заголовок, «нет совпадений», категории) — ключами в
  `internal/i18n/i18n.go` для `ru`+`en` (см. `plans/completed/i18n.md`).
