# Фича: поиск в панели ответа

## Цель

Изначально: фильтр есть только в списке файлов (`files.go`), поиска по тексту ответа
нет. Нужен поиск с живой подсветкой и навигацией по совпадениям.

Реализовано как **единый компонент поиска** на верхней строке фрейма: поскольку
панель файлов и панель ответа нельзя редактировать текстом, любой печатный ввод в
активной из них открывает этот поиск. Для ответа — подсветка/навигация по
совпадениям; для файлов — живой фильтр списка. Отдельный хоткей `Ctrl+F` не
нужен (убран).

## Предпосылки

- Строки панели ответа — `respBodyLines` / `render_resp.go` (`internal/tui`).
- Ввод — `bubbles/textinput` (уже используется для `saveAs` в `app.go`).

## Дизайн (final)

- `searchBox` (`internal/tui/find.go`): `{input *textinput.Model, target pane}`,
  target = `paneFiles` или `paneResp`.
- Строка поиска рисуется на верхней строке фрейма вместо шапки имени файла
  (`render.go` `View`), поэтому панели и их координаты мыши/выделения не
  сдвигаются.
- Открытие: печатный символ в `paneFiles` / `paneResp` → `openSearch(target, s)`
  (в `keys.go` через `printableRunes`).
- `Esc`/`Ctrl+C` закрывают; `Enter`/`↓` и `Shift+Tab`/`↑` — навигация по
  совпадениям ответа; совпадение центрируется по вертикали.
- Локальный фильтр файлов внутри `renderFilesPanel` удалён; `p.filter`
  управляется из строки поиска (`applyFileFilter`); координаты мыши файлов
  пересчитаны (`mouseToFilesRow`, `profileTitleRowAbs`, `fileListMaxRows`).
