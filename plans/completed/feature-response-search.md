# Фича: поиск в панели ответа

## Цель

Сейчас фильтр есть только в списке файлов (`files.go`), поиска по тексту ответа нет.
Нужен `Ctrl+F` с живой подсветкой и навигацией по совпадениям.

## Предпосылки

- Строки панели ответа — `respBodyLines` / `render_resp.go` (`internal/tui`).
- Ввод — `bubbles/textinput` (уже используется для `saveAs` в `app.go` и фильтра
  файлов).
