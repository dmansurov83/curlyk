# Фича: пакетный запуск всех запросов файла

## Цель

Один запуск всех `###`-блоков файла с итоговой сводкой успех/ошибка. Usable как
sanity-check и для CI-подобного прогона.

## Предпосылки

- `ParseFile(m.ed.Text())` даёт все блоки; `runner.Run` — выполнение одного.
- Модель сообщений bubbletea (`tea.Msg`/`tea.Cmd`) — для неблокирующего запуска.
- Processing options — см. feature-processing-options (опции должны соблюдаться).

## Дизайн

- Команда в action menu «Выполнить все» (последовательная итерация по блокам).
- Сводка в панели ответа: строка на запрос (имя/метод/URL/код/длительность/результат)
  + агрегированный итог.
- Последовательный запуск по умолчанию; опционально параллельный с ограничением
  конкурентности, если запросы независимы.
