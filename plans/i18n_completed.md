# Интернационализация (i18n) — план работ

## Цель

Вынести весь пользовательский интерфейс (статусные сообщения, подсказки, метки панелей,
пункты меню, промпты, placeholder, сообщения об ошибках в `main.go`) из жёстко
зашитого русского текста в каталог переводов. Поддержать минимум два языка: `ru` (по
умолчанию) и `en`.

## Предпосылки (текущее состояние)

- Все UI-строки хардкожены в Go: `render.go`, `app.go`, `files.go`, `actionmenu.go`,
  `clipboard.go`, `main.go`.
- Зависимостей для i18n нет (только bubbletea, lipgloss, textinput, yaml, runewidth).
- Классы строк:
  - статусные `m.status = "..."` — ~35 шт. (clipboard.go, files.go, actionmenu.go, app.go);
  - статичные метки/подсказки — ~10 шт. (render.go, actionmenu.go, app.go);
  - строки с конкатенацией `"..." + err.Error()` — ~10 шт.
- **Критично:** 5 тестовых файлов делают `strings.Contains` по русским подстрокам —
  `render_top_test.go` (`"Файл:"`, `"Готов"`), `actionmenu_height_test.go` (`"Файл:"`),
  `copybtn_test.go` (`"Скопировать"`), `neterr_test.go` (`"Сетевая ошибка"`,
  `"Сетевой запрос не выполнен"`), `conflict_merge_test.go` (`"Время:"`).
  → Дефолтный язык остаётся `ru`, иначе тесты ломаются.

## Подход

Простой пакет `internal/i18n` без тяжёлых библиотек:

- каталог переводов `map[lang]map[key]string` + функция `T(key string, args ...any) string`
  (обёртка `fmt.Sprintf`);
- выбор локали: env `CURLYK_LANG` → `settings.Lang` → дефолт `ru`;
- строки с подстановкой — через шаблоны вроде `"Не удалось сохранить: %s"`.

Плюрализация не нужна: единственная числовая строка `"Скопировано (%d симв.)"` не требует
форм множественного числа на целевых языках.
