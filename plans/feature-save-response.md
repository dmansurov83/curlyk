# Фича: сохранение ответа в файл

## Цель

Ответ можно прочитать/скопировать, но нельзя сохранить целиком в файл. Нужен экспорт
сырого тела ответа в файл.

## Предпосылки

- `lastBody` (`app.go:46`) хранит сырое тело ответа.
- Механизм запроса пути — `saveAs`/`textinput` (`app.go`).
- Hotkey `Ctrl+D` (дамп), `Ctrl+S` — проверить занятость в `keys.go` перед выбором.

## Дизайн

- Hotkey (например `Ctrl+W` или другой свободный) в панели ответа — запрос пути через
  существующий механизм `saveAs`.
- Сохранять сырое тело (`lastBody`), а не раскрашенный текст (или выбор через пункт
  меню).
