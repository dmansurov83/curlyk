# Proposal

## Why

Оконный редактор `cmd/curlyk-gui` на Fyne уже собирается и проходит тесты, но по
возможностям отстаёт от TUI: в нём нет справки по клавишам, навигации по
запросам, поиска и подсветки в панели ответа, конвертации вставленного cURL и
редактирования профилей. Из-за этого один и тот же `.http`-файл в окне и в
терминале ведёт себя по-разному, а пользователь GUI вынужден помнить скрытые
хоткеи. Работа над GUI начата (не закоммичена), её нужно довести до
функционального паритета с TUI, чтобы оконный режим считался готовым.

## What Changes

- **Панель ответа как полноценная панель**: клик по ней делает её активной; в ней
  работает поиск (набор текста в активной панели и `Ctrl+F`) с подсветкой
  совпадений и счётчиком; тело JSON подсвечивается тем же `internal/jsonlex`;
  в дампе ответа показываются отправленные заголовки запроса.
- **Справка по горячим клавишам**: `F1` показывает/скрывает справочную панель в
  правой панели; пока ответа нет, справка показывается автоматически; первый
  выполненный запрос возвращает панель ответа.
- **Навигация по запросам**: `Ctrl+G` открывает попап со списком запросов файла
  (`@name` → заголовок `###` → `METHOD URL`) с фильтром по мере ввода и
  переходом на строку запроса.
- **Конвертация cURL при вставке**: `Ctrl+V` с curl-командой вставляет
  сконвертированный `.http`-блок; распознавание команды выносится в общий
  `internal/curl`.
- **Редактирование профиля**: профиль из боковой панели открывается в редакторе
  как обычный файл, сохраняется тем же `Ctrl+S`; активный профиль продолжает
  подставляться при запуске.
- **Переключение панелей**: `Tab`/`Shift+Tab` переводят фокус между файлами,
  редактором и ответом; `Esc` закрывает оверлеи в порядке «меню → автодополнение
  → поиск».
- **Иконка запуска в гуттере**: `▶` слева от номера строки каждого запроса,
  клик открывает меню запроса (как в TUI).
- **Алиасы хоткеев**: `Ctrl+R` — выполнить, `Ctrl+Shift+Z` — повторить
  отменённое; текущее поведение GUI не ломается.
- **Документация**: раздел GUI в `README.md` дополняется таблицей новых
  хоткеев и описанием паритета.

## Capabilities

### New Capabilities

- `desktop-gui`: поведение оконного редактора `.http` на Fyne — трёхпанельное
  окно, выполнение запросов, панель ответа, справка, навигация, поиск,
  автодополнение, профили и работа с буфером обмена.

## Impact

- **Код**: `internal/gui/*` (основной объём), `internal/curl` (общий
  `IsCurlCommand`), `internal/i18n` (существующие ключи `help.*`, `nav.*`,
  `find.*` переиспользуются; при необходимости добавляются `gui.*`),
  `internal/httpfile` (метаданные запроса для навигации и дампа, если
  понадобятся), `internal/tui` (перевод на общий `IsCurlCommand`).
- **Тесты**: новые тесты `internal/gui` на поиск/навигацию/справку/вставку cURL/
  профили и панельный фокус; существующие тесты остаются зелёными.
- **Сборка**: без изменений — GUI по-прежнему требует cgo, TUI собирается с
  `CGO_ENABLED=0`.
- **Вне объёма**: релизная упаковка GUI, иконка и Windows-ресурсы
  `cmd/curlyk-gui`, а также отмена/повтор в стиле TUI там, где GUI сознательно
  следует платформенным соглашениям.
